NIKA Encrypted Backups

A personal integration operated by Denis Vasiljev to store encrypted N.I.K.A. backup archives in his Google Drive using rclone.

Why Google Drive access is needed

The integration uses Google OAuth to authorize backup operations without sharing the Google account password. It requests the https://www.googleapis.com/auth/drive.file scope for files created by, opened with, or explicitly shared with the application. This supports uploading, checking, retrieving and managing its backup files.

The integration is intended for the operator's personal use. This public website provides application and privacy information; it does not provide sign-in, run backups or receive backup contents or OAuth tokens.
