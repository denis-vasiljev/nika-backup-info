Drive Automation · NIKA Encrypted Backups

Privacy Policy

Effective date: 14 October 2026

This policy covers NIKA Encrypted Backups, a personal Google Drive backup integration operated by Denis Vasiljev, and this informational website.

Data accessed and purpose

The integration uses Google OAuth and the drive.file permission to work with backup files it creates or that are explicitly made available to it. It processes encrypted backup contents and associated file metadata, such as file identifiers, names, sizes and modification times, as needed to upload, verify, retrieve and manage personal backups. It does not request unrestricted access to all Google Drive files.

Authorization and storage

Google handles account sign-in. The integration uses OAuth access and refresh tokens to perform authorized backup operations, including unattended operations. It does not ask for the Google account password. Backup archives are stored in the operator's Google Drive. OAuth tokens and encryption keys are private operational credentials and are not published on this website or in its public repository.

Use and sharing

Google user data is used only to provide and maintain the personal backup functionality. It is not sold, used for advertising or used to train general-purpose AI models. Backup operations transfer data between the operator-controlled backup environment and Google Drive. This website does not receive backup files or OAuth tokens.

The integration's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion and access control

The operator controls backup retention and deletion. Backup files remain in Google Drive until removed by the operator or the configured backup retention process. Revoking OAuth access prevents future authorized API operations but does not automatically delete existing backup files. The operator can revoke access in the Google Account's third-party connections settings and separately delete retained backups and local authorization data.

This public website

These static pages have no sign-in form, analytics scripts, advertising or application cookies. GitHub Pages hosts the site and may process visitor technical information, including IP addresses and request logs, under the GitHub Privacy Statement.

Contact and updates

For privacy questions or requests, contact Denis Vasiljev at dvasiljev@gmail.com. Changes to this policy will be published on this page with an updated effective date.
